### [Tech Pocket](https://tech-pocket.com/)
Plataforma HR todo-en-uno que permite a empresas gestionar empleados, vacaciones (PTO), contratos, documentos, equipamiento, entidades legales y facturación desde un solo lugar. Incluye flujos de aprobación, control de acceso por roles (RBAC), notificaciones vía Slack y email, organigrama interactivo y soporte multilenguaje (ES/EN).

**Tech:** React · TypeScript · Supabase · Tailwind CSS
